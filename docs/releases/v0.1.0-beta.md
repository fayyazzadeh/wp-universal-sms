# WP Universal SMS v0.1.0-beta

## What's New

- Initial WordPress plugin foundation.
- Provider-agnostic `SMSProviderInterface`.
- Normalized `SMSResponse`.
- Provider registry with a default provider.
- Generic HTTP/REST provider.
- Request template interpolation.
- Basic response mapping.
- Normalized transport errors.
- Sanitized response logging boundary.
- Composer and PHPUnit project configuration.
- Initial architecture and provider documentation.

## Changed

Nothing; this is the first development release.

## Fixed

No production fixes; this is the first development release.

## Security

- Authentication values are not included in normalized provider error messages.
- Provider response diagnostics redact keys matching token, secret, password, API key, and authorization patterns.

## Upgrade Notes

This is a development/beta release. Provider configuration and public APIs may evolve before the first stable release.
