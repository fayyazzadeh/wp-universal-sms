# WP Universal SMS v0.2.0-beta

## What's New
- Added the first professional WordPress Admin UI.
- Added Dashboard, Gateway, Providers, and Logs screens.
- Added a dedicated admin settings boundary.
- Added definition-driven provider metadata.
- Added responsive RTL-first admin styling.
- Added WordPress capability and nonce checks for gateway mutations.
- Added secret-safe admin read models.

## Changed
- Plugin bootstrap now registers its admin menu, assets, and admin action handler.

## Fixed
- No production fixes in this beta release.

## Security
- Gateway mutations require manage_options.
- Gateway mutations require a WordPress nonce.
- API keys and other secret fields are not exposed through the dashboard read model.
- Logs UI is designed to show normalized diagnostics without credentials.

## Upgrade Notes
Upgrade from 0.1.0-beta is additive. Existing SMS Core and provider contracts remain the integration boundary.

## Next
The next phase will focus on the customer-owned GSM Agent for USB/COM-connected GSM modems. Licensing remains a later phase.
